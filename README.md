# SPACE WAR 0.1.6

First playable loop. Not 1.0 until speed sticks, hold-fire specials, and ranks that buy stats.

Browser homage to Michael Read’s 2001 Palm OS freeware game. Original mechanics, original art. Not a Paramount product. Not a clone of any existing source port.

Open `index.html` in a phone or desktop browser.

## How to play

1. Pick a hull (Union, Empire, Web, Swarm, or Cube), then tap **Engage**.
2. Tap a highlighted hex to plot your course. Tap a second hex to aim — Phaser is a short beam; Torpedo is one hex, limited ammo. **Skip fire** to only move.
3. Tap **GO**. Every ship moves and fires at once. Lead the hex they will *end* on.
4. Collisions hurt and bounce. Last ship standing wins. Ranks after victories are flavor only.

## Hulls

| Hull   | Feel                |
|--------|---------------------|
| Union  | Balanced            |
| Empire | Fast, weak          |
| Web    | Slow, strong        |
| Swarm  | Fragile, extra move |
| Cube   | Tank, short move    |

God panel is `?god=1` (off the public URL by default).
